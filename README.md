# Python Day 134 - Unique Elements in Two Lists

This Python program finds elements that are present in only one of the two lists.

## Example

First list: `[10, 20, 30, 40]`

Second list: `[30, 40, 50, 60]`

Output:

```text
Unique elements: [10, 20, 50, 60]
```

## Concepts Used

- Lists
- `for` loop
- `if` statement
- `not in` operator
- `append()` method

## How It Works

The program checks both lists. It adds elements that are not present in the other list to a new list called `unique`.
